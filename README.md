# Algorithm Visualizer

An interactive web application for visualizing common algorithms and data structures. The goal of the project is to make it easier to see how algorithms operate step-by-step rather than only looking at the final result.

The project is written primarily in JavaScript, along with HTML and CSS, and is actively being developed.

## Current Features

### Sorting Algorithms

- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort

Sorting algorithms can be stepped through interactively, allowing comparisons, swaps, and other operations to be observed as each algorithm executes.

### Data Structures

#### Fixed-Size Arrays

Interactive visualization of common fixed-size array operations.

#### Singly Linked Lists

Interactive visualization of singly linked lists, including traversal, insertion, ordered insertion, deletion, and other supported list operations.

Clear and Reverse are currently planned but not yet implemented.

## Interactive Visualization

The visualizer allows users to move forward and backward through individual operations instead of executing an entire algorithm at once.

Visual highlighting shows the elements or nodes involved in the current operation, making it possible to observe how the internal state of an algorithm or data structure changes over time.

## Technologies

## Running the Project

Clone the repository and open the project using a local web server.

For example, the project can be run using the Live Server extension in Visual Studio Code.
